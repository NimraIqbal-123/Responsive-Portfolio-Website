# 🌐 Responsive Portfolio Website

A modern and fully responsive personal portfolio website developed using HTML5, CSS3, Bootstrap 5, and JavaScript. The website showcases my skills, projects, education, experience, and contact information in a clean and professional layout.

---

## ✨ Features

- Responsive Design
- Bootstrap 5 Layout
- Professional Navigation Bar
- Hero Section
- About Me
- Skills Section
- Projects Showcase
- Education Timeline
- Experience Section
- Resume Download Button
- Contact Form
- Footer with Social Links
- Smooth Scrolling
- Scroll-to-Top Button
- Mobile Friendly

---

## 🛠 Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Remix Icons

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/yourusername/responsive-portfolio-website.git
```

Open the project

```bash
cd responsive-portfolio-website
```

Launch the website by opening `index.html` in your browser.
